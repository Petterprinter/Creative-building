# Creative Building

A sandbox repository for building and experimenting with a wide variety of creative projects.

## Purpose

This repo is a single home for diverse creative work — apps, websites, documents, data, presentations, and more. Projects here range from quick experiments to more polished pieces. When a project outgrows this repo, it should be spun out into its own dedicated repository.

## Folder Structure

| Folder | Contents |
|---|---|
| `apps/` | Web apps, CLI tools, scripts, and other runnable software |
| `sites/` | Static websites, landing pages, and web experiments |
| `docs/` | Written documents, reports, and written content |
| `notebooks/` | Jupyter notebooks and data exploration work |
| `slides/` | Presentations and slide decks |
| `spreadsheets/` | Excel files, CSV datasets, and tabular data |
| `misc/` | Anything that doesn't fit the above categories |

## Conventions

- Each project lives in its own subfolder: `apps/my-project/`, `sites/my-site/`, etc.
- Include a short `README.md` inside each project folder explaining what it is.
- If a project grows serious and needs its own repo, extract it cleanly rather than leaving dead code here.
