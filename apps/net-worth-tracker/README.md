# Net Worth Tracker

A single-file web app for tracking personal net worth across cash accounts, investments, and debts.

## Features

- Add and manage assets (cash, savings, brokerage, 401k, crypto, etc.)
- Add and manage liabilities (credit cards, loans, mortgage, etc.)
- Live summary: net worth, total assets, total liabilities, debt ratio
- Donut charts for asset allocation and liability breakdown
- Snapshot history — save your net worth at a point in time to track progress
- All data stored in browser `localStorage` — no server, no sign-up

## Usage

Open `index.html` directly in any modern browser. No build step required.
